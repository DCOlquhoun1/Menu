## Operational note — the 30-minute buffet window

Buffet opens 19:30, presentations start 20:00. A single service line moves roughly four
guests a minute, so 130 covers takes over half an hour and the last guests would still be
eating into the presentations.

- Run **two service lines** (double-sided buffet) — halves the queue to ~15 minutes, costs
  an extra set of service kit rather than extra staff.
- **Desserts and coffee at 21:00**, after the presentations, not in the same window.
- **Clear at 20:00** — plates down before the first slide.
